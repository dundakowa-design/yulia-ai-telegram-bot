# 🤖 Yulia AI • Мультимодальный Telegram-бот

Умный персональный мультимодальный ИИ-ассистент в Telegram, разработанный на Python с интеграцией современных нейросетей и обходом сетевых ограничений через Cloudflare Workers. Бот использует единый адаптивный интеллект: сам определяет тип задачи и подбирает стиль и глубину ответа без ручного переключения ролей.

## ✨ Основные возможности

- 💬 **Умный диалог с памятью:** единый адаптивный помощник автоматически подбирает подход к программированию, текстам, аналитике, обучению, творчеству и бытовым вопросам — переключать роли вручную не нужно.
- 🎤 **Голосовой ввод и озвучка (STT & TTS):** распознавание голосовых сообщений через `Whisper` и озвучивание ответов бота живым мужским или женским голосом.
- 👁 **Компьютерное зрение (Vision API):** анализ фотографий и скриншотов.
- 🎨 **Генерация и редактирование фото:** создание картинок по запросу и редактирование загруженных снимков (замена фона, удаление объектов) через `GPT Image 2.6`.
- 📄 **Анализ документов:** чтение файлов `.pdf`, `.docx` и `.txt` прямо в чате.
- 🌐 **Стабильная работа без VPN:** маршрутизация запросов Telegram Bot API через собственный reverse-proxy на Cloudflare Workers.

## 🛠 Стек технологий

- **Язык:** Python 3
- **Библиотеки:** `pyTelegramBotAPI`, `openai`, `python-dotenv`, `pypdf`, `python-docx`
- **Инфраструктура:** OpenAI-compatible API, Cloudflare Workers

## 🚀 Как запустить проект локально

1. Склонируйте репозиторий и установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` в корне проекта и добавьте свои ключи:
   ```env
   BOTHUB_API_KEY=ваш_api_ключ
   TELEGRAM_TOKEN=ваш_токен_telegram_бота
   ```
3. Запустите бота:
   ```bash
   python tg_bot.py
   ```
